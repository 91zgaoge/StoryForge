# 按正文重写大纲：确认后才保存

**状态**：已落地 v0.53.5。  
**日期**：2026-08-25  
**对照版本**：v0.53.4 → v0.53.5

## 用户可见契约

输入「写后续的故事大纲，同时生成后续的场景大纲」（或同类按正文重写大纲）后：

1. 模型只产出草稿，**不写库**。
2. 幕前弹出可编辑对话框：故事大纲 / 场景大纲（按本次靶显示）。
3. **确认**：把用户当前编辑写入幕后大纲；纸面不改。
4. **取消**：废弃草稿，库里仍是旧大纲。
5. **重写**：用原指令再生成一轮，替换对话框内容；仍须确认才落库。重写失败保留上一稿。

角色/世界观-only 刷新仍立即落库 + 只读报告（本版不改）。含大纲的请求一律确认后才写大纲。

## 不变量

- `scenes.content` 永不因本作业改变。
- 确认前 `story_outlines` / `scenes.outline_content` 字节与生成前一致。
- 用户确认稿按手改落库（不再按正文删人名）；模型预览稿仍接地后再展示。
- 重写不走续写 Append。

## 实现要点

- `execute`：解析后 `preview_refresh_outlines`，返回 `result_kind=asset_refresh` + `asset_refresh_draft`。
- 新 IPC `confirm_asset_refresh`：确认才 `persist`。
- 重写：对话框再调 `smart_execute`（同一指令），忽略迟到结果。
