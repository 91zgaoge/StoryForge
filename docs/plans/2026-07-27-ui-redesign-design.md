# StoryMoss UI 重塑设计文档

> 目标：打造「极致简洁的幕前写作沉浸式体验」与「幕后机械式精美细致后台」相结合的完整视觉系统。
> 日期：2026-07-27
> 方案：B — 双模式设计系统

---

## 1. Visual Thesis

**一张会呼吸的稿纸，与一面会说话的仪表板。**

幕前让读者/作家忘记软件存在，只面对文字与纸张；幕后让设定控感到每一颗螺丝都可调。两种世界通过统一的底层 token 连接，但在材质、光线、动效上形成强烈对比。

## 3. Typography

### 幕前
- **正文**：`'LXGW WenKai', 'Noto Serif SC', 'PingFang SC', serif`
- **UI 标签**：`'SF Pro Display', 'PingFang SC', system-ui, sans-serif`
- **标题字号**：18–22px 章节标题，14px 工具栏文字
- **正文行高**：1.8
- **段间距**：0.75em
- **首行缩进**：2em

### 幕后
- **数据/代码**：`JetBrains Mono, monospace`
- **标题/界面**：`'SF Pro Display', 'PingFang SC', sans-serif`
- **正文字号**：13–14px
- **行高**：1.5
- **标签全大写**：`letter-spacing: 0.05em; font-size: 11px; text-transform: uppercase;`

## 4. Components

### 4.1 幕前组件

#### Ghost Chrome（幽灵工具栏）
- 顶部标题栏、底部输入栏、侧边字数统计默认 100% 可见。
- 鼠标静止 3 秒后，非核心元素淡出到 `opacity: 0.08`，仍保留交互热区。
- 鼠标移动、键盘输入、点击立即恢复 `opacity: 1`，过渡 0.25s ease-out。

#### AI Hint（文思提示）
- 以浅灰墨迹形式出现在光标后，无背景框。
- 颜色：`--ink-500` 或带 50% 透明度。
- 按 `→` 接受时，文字像墨水渗入般从提示色渐变为正文色（0.2s color transition）。

#### RichTextEditor
- 最大宽度 720px，居中对齐。
- 编辑区上下预留大量呼吸空间（≥10vh）。
- 滚动条极细（4px），颜色与 parchment 融合。

### 4.2 幕后组件

#### Panel（机械面板）
- 背景：`--cinema-850`
- 边框：`1px solid rgba(255,255,255,0.06)`
- 圆角：8px
- 阴影：`0 4px 24px rgba(0,0,0,0.4)`
- 标题区：11px 大写标签 + 图标

#### Toggle Switch
- 轨道：圆角 999px，深底 + 内阴影。
- 滑块：金色，active 时带微光。
- 切换动画：0.2s cubic-bezier(0.34, 1.56, 0.64, 1)（轻微过冲）。
- 点击反馈：`active:scale-95`。

#### Button
- Primary：深底 + 金边 + 金色文字，hover 时背景略微提亮。
- Secondary：透明底 + 细边框 + 灰白文字。
- active 统一 `scale-95`。

#### Input / Select
- 背景：`--cinema-800`
- 边框：1px solid `--cinema-700`
- 聚焦：边框变为 `--cinema-gold`，外发光 `0 0 0 2px rgba(212,175,55,0.15)`。

#### Accordion
- 展开使用弹簧曲线 `cubic-bezier(0.34, 1.56, 0.64, 1)`。
- 折叠时图标旋转 180°。

## 6. Depth

### 幕前
- **无阴影**，只靠背景色阶区分层次。
- 纸张表面保持绝对扁平，让文字浮于其上。
- 唯一深度：AI 提示的轻微透明度变化。

### 幕后
- 使用多层阴影营造仪器深度：
  - 面板：`0 4px 24px rgba(0,0,0,0.4)`
  - 悬浮按钮：`0 8px 32px rgba(0,0,0,0.5)`
  - 下拉/弹层：`0 16px 48px rgba(0,0,0,0.6)`
- 半透明边框（`rgba(255,255,255,0.06)`）强化面板边缘。

## 7. Do / Don't

### Do
- 幕前保持大面积留白，按钮/文字尽量小且轻。
- 幕后使用数据化字体展示字数、token、进度。
- 切换前后台时保持光标/滚动位置。
- 所有可点击元素提供 hover/active 反馈。
- 对低性能设备使用 `prefers-reduced-motion` 降级。

### Don't
- 幕前不要使用大圆角、强阴影、彩色背景块。
- 幕后不要使用暖色 parchment 或手写体。
- 不要让 AI 提示以弹窗、横幅、闪烁方式出现。
- 不要在前台使用多个并排的侧边栏。

## 8. Responsive

### 幕前
- 桌面：720px 编辑区，左右呼吸边距。
- 平板：编辑区宽度 90%，字号 17px。
- 小屏：隐藏侧边字数，底部输入栏全宽。

### 幕后
- 桌面：左侧 200px 导航轨，右侧 12 列网格。
- 平板：导航轨折叠为图标轨（64px）。
- 小屏：导航轨完全隐藏，通过汉堡菜单呼出，卡片单列堆叠。

## 9. Prompt Guide

向实现者描述任一界面时，使用以下结构：

1. **模式**：这是「墨纸」还是「机械」？
2. **表面**：背景色 token、边框、圆角、阴影。
3. **文字**：字体、字号、颜色、行高。
4. **交互**：hover / active / focus 状态与动效曲线。
5. **优先级**：必须现在做，还是可后续迭代？

示例：
> 「机械」模式下的设置面板：背景 `--cinema-850`，8px 圆角，1px 半透明边框，标题使用 11px 大写标签，折叠展开使用 `cubic-bezier(0.34, 1.56, 0.64, 1)`，按钮 active 时 `scale-95`。
